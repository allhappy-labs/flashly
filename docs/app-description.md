# App Description

## Overview
It is a flashcard learning platform with a mobile study app and a companion web app. It helps learners create decks, generate cards from study material, and practice with multiple study modes. The experience focuses on fast setup, flexible practice, and clear progress tracking.

## Feature List (User-Facing)

### Create and organize decks
- Create new decks with names, descriptions, and category accents
- Edit deck details at any time
- See at-a-glance counts for total, new, learning, review, and due cards
- Sort decks by recent study or newest added

### Create and edit cards
- Add cards with front/back content
- Add optional details like category, part of speech, example sentences, and tags
- Attach images to cards
- Attach or generate audio for pronunciation or recall
- Star favorite cards for focused study

### Study and practice modes
- Classic study mode with swipe-based grading and spaced repetition
- Learn mode with goals (cram vs memorize), question types (multiple choice, written), and answer direction (term vs definition)
- Test mode for formal recall
- Match mode for fast pairing practice
- Write mode for typed recall
- Browse mode for flipping through cards with quick audio playback

### Personalized learning controls
- Daily study goal with quick step controls
- Option to allow extra new cards beyond the daily goal
- Optional auto-grading based on how quickly you answer
- Haptic feedback toggle

### Progress and analytics
- Deck overview with retention percentage and due counts
- Detailed analytics: daily activity, time spent, review streaks, and rating breakdowns
- Trend indicators and last activity highlights

### Import and export
- Import decks from text or packaged exports (including images and audio)
- Preview parsed cards before importing
- Export decks for sharing or backup

### AI-assisted generation (mobile + web)
- Generate flashcards from pasted notes or uploaded study material
- Choose formats such as Q&A, cloze, or definition style
- Optionally enrich cards with intentional single-choice questions and concise explanations; ordinary multiple-choice practice continues deriving choices from the deck
- Optional audio generation for card fronts
- Multi-language deck generation (web)
- Download generated decks as a shareable package (web)

### Web account and billing
- Email-based sign-in
- Profile settings with display name, username, and avatar
- Subscription management, invoice history, and cancellation

### Help and about
- Built-in help center link
- About screen with app version
