# Flashly Promotional Website Structure

Effective educational landing pages start with a clear above-the-fold pitch and CTA, followed by concise, scannable sections that highlight benefits and build trust. Below is a proposed site map for **Flashly**, with pages and section outlines.

**Tone & branding**
- Friendly, motivating tone
- Blue for trust, orange accents for energy, green for positive feedback
- Clean sans-serif font (e.g. Inter or Poppins), generous whitespace, scannable headings/bullets

---

## Home Page

### Hero (Above the fold)
- **Headline:** “Learn faster with Flashly”
- **Subheading:** AI-generated flashcards + spaced repetition + fun study modes
- **Primary CTA:** “Get the App” / “Start Generating”
- **Visual:** Student using the app or device mockup

### Key Features Overview
A compact 3–4 item grid (icons + 1–2 lines each):
- AI Card Generation
- Spaced Repetition
- Multiple Study Modes
- Progress Tracking

### Flashcard Generator (Web Demo)
- Short teaser: paste notes → get flashcards instantly
- CTA: “Try It” (link to the web app)
- Optional interactive demo or “before/after” example

### Target Personas Callouts
Card row linking to persona pages:
- Exam Students
- Language Learners
- Lifelong Learners

### Testimonials / Social Proof
- 1–3 short quotes (real if possible; otherwise clearly marked as examples)
- Neutral background; orange quote marks for emphasis

### Final Call to Action
- “Download Flashly” with App Store / Play Store badges
- Secondary CTA: “Try Web App”

### Footer
- Links: Home, Features, Personas, Resources, Pricing, Help Center, Contact
- Legal: Privacy, Terms

## Pricing (One-Off Payments Only)

Flashly does **not** offer subscriptions. All upgrades are **one-time payments** (one-off), not recurring.

### Free (Auto-enabled)
- Price: **Free**
- Includes (one-off usage limits):
  - **200** flashcards generation
  - **10** audio for cards
  - **10** images for cards

CTA ideas:
- “Start Free”
- “Try the Generator”

### Pro (One-Time Purchase)
- Price: **€10** (one-off)
- Includes (one-off usage limits):
  - **1,000** flashcards generation
  - **100** audio for cards
  - **300** images for cards

CTA ideas:
- “Upgrade to Pro (One-Off)”
- “Unlock Pro Features”

### Pricing Notes (Recommended microcopy)
- “Pay once. No monthly fees.”
- “No subscriptions. No recurring charges.”
- If accurate, add: “Purchases sync across devices on your account.”

---

## Global UX Guidelines

- Keep sections short and scannable: headings + bullets
- Put at least one CTA per page
- Use brand colors consistently:
  - Blue for headings/buttons (trust)
  - Orange for highlights/primary CTA (energy)
  - Green for success indicators (progress)

---

## Sources / Rationale (Internal Notes)
Best practices for educational landing pages recommend:
- Strong hero section (headline + subheadline + primary CTA)
- Multiple CTAs throughout
- Scannable feature sections and social proof near decision points
- Persona-tailored messaging for higher relevance and engagement
- Help centers organized into simple categories for fast discovery
- Reinforcing proven learning methods (e.g., spaced repetition)
