Getting started is quick. Use these three steps to go from zero to your first study session.

## 1. Create your account

- Sign in with your email.
- Set your display name and username in profile settings.

## 2. Create your first deck

- Add a clear deck name and description.
- Choose a category accent color to make it easier to spot.

## 3. Add cards and start studying

- Add cards manually or generate a deck from your notes.
- Set a daily goal so each session stays short and focused.

If you already have notes, try the generator to create cards in seconds.
